# Codex 远程控制一键部署

## 使用方法

双击 `deploy.cmd`，脚本会自动完成：

1. 检查 Node.js、pnpm 和 Codex/ChatGPT Desktop。
2. 安装 OpenCodex 依赖。
3. 首次部署时生成访问密码。
4. 启动 OpenCodex 网页控制。
5. 启动手机电源控制页面。
6. 应用“屏幕熄灭但电脑保持运行”策略。

部署完成后会打印手机访问地址。

## 合并控制页

手机访问 `http://电脑IP:3740` 会打开一个合并页面，包含两个标签：

- `Codex`：直接嵌入 Codex 网页控制
- `电源`：关机、重启、睡眠、休眠

在 Codex 页面右下角也有一个“电源”按钮，点一下就能切到电源控制。

## 开机自启动

一键部署默认会先把自启动快捷方式放进当前用户的启动文件夹：

`C:\Users\当前用户名\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup\CodexRemoteControl.lnk`

以后登录 Windows 会自动在后台启动 OpenCodex 和电源控制。

如果要改成“开机即启动、不用登录”的系统级自启动，请右键管理员运行：

`install-system-autostart.cmd`

它会创建计划任务 `CodexRemoteControlSystem`，并自动删除上面的登录后快捷方式。

不需要自启动时，删除快捷方式或计划任务即可。

## Tailscale

一键部署会检查电脑上的 Tailscale：

- 已安装并登录：自动读取 Tailscale IP 并打印访问地址。
- 已安装未登录：自动打开登录页面，在浏览器完成登录即可。
- 未安装：有 winget 时自动安装，否则提示去 `https://tailscale.com/download` 安装。

手机端需要在应用商店安装 Tailscale，并登录和电脑相同的账号。

## 访问地址

- OpenCodex 网页：`http://电脑IP:3737`
- 电源控制页面：`http://电脑IP:3740`
- 电脑 IP 可使用局域网地址或 Tailscale 地址，部署完成后脚本会显示。

## 手动启动

如果服务没有开机自启，可以分别双击：

- `start-phone-control.cmd`：启动 Codex 网页
- `power-control\start-power-control.cmd`：启动电源控制
- `keep-running.cmd`：重新应用熄屏保持运行

## 开机

完全关机后需要 Wake-on-LAN，步骤见 `power-control\README.md`。

## 安全

- 访问密码不要外传。
- 不要把这个项目直接暴露到公网。
- 手机远程建议使用 Tailscale。
