# Codex 手机远程控制

基于 OpenCodex 的 Codex/ChatGPT Desktop 远程控制方案，支持手机浏览器访问完整对话，并提供电源控制和一键部署。

## 功能

- 手机浏览器远程控制 Codex，显示完整对话流程
- 中文界面
- 电源控制：关机、重启、睡眠、休眠
- Wake-on-LAN 开机说明
- 一键部署脚本
- 开机自启动（登录后自启动 / 系统级自启动脚本）

## 使用的开源项目

- [OpenCodex](https://github.com/RyensX/OpenCodex)：Codex Desktop 网页中间层
- [Tailscale](https://tailscale.com)：手机远程组网（客户端，不在本仓库内）
