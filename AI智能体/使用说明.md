# AI 智能体使用说明

## 1. 最快体验（不用配置任何密钥）

在项目根目录运行：

```bash
python -m agent run
```

这会同时启动：

- 控制台对话（直接在窗口里和 AI 聊天）
- 记忆服务
- 情绪服务
- 联网服务（演示模式）
- Telegram 聊天服务（没配 token 时自动跳过）
- 内容生成服务
- 短视频发布服务（演示模式）

控制台里可以输入：

- `/mood`：查看当前情绪
- `/memory`：查看记忆
- `/quit`：退出

## 2. 配置真实 AI 对话

1. 把 `.env.example` 复制一份，命名为 `.env`。
2. 在 `.env` 里填写：

```text
AI_API_KEY=你的模型密钥
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini
```

3. 重新运行：

```bash
python -m agent run
```

支持任何 OpenAI 兼容接口，`AI_BASE_URL` 和 `AI_MODEL` 按你的服务商填写即可。

## 3. 接入 Telegram 聊天

1. 找 BotFather 创建一个 Telegram 机器人，拿到 `TELEGRAM_BOT_TOKEN`。
2. 在 `.env` 里填写：

```text
TELEGRAM_BOT_TOKEN=你的机器人令牌
```

3. 运行：

```bash
python -m agent run
```

聊天服务会自动轮询 Telegram 消息并回复。

## 4. 开启真实联网搜索

默认是演示搜索，不会访问网络。需要真实搜索时，在 `.env` 填写：

```text
SEARCH_PROVIDER=tavily
SEARCH_API_KEY=你的搜索服务密钥
```

支持的服务：

- `tavily`
- `serper`
- `brave`

## 5. 短视频发布

默认是演示模式，不会真的发视频。需要真实发布时：

1. 到抖音开放平台或 TikTok 开发者平台申请凭证。
2. 在 `.env` 填写 `DOUYIN_CLIENT_KEY`、`DOUYIN_CLIENT_SECRET` 或 `TIKTOK_CLIENT_KEY`、`TIKTOK_CLIENT_SECRET`。
3. 确认授权完成后，把 `DRY_RUN=0`。

未配置凭证前，请保持演示模式，避免误发。

## 6. 常见问题

- 没有 Python：使用 Codex 自带运行环境，或用 Python 3.11 以上版本运行。
- 控制台没反应：先确认已经安装了依赖，本项目使用 Python 标准库，通常无需安装第三方包。
- Telegram 没回复：检查 token 是否正确、网络是否能访问 Telegram。
- 发视频失败：确认已配置平台凭证，且 `DRY_RUN=0`。
