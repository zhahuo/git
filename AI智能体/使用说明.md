# AI 智能体完整使用说明

## 一、这个项目能做什么

这是一个本地运行的 AI 智能体，包含 7 个并行模块：

| 模块 | 作用 |
| --- | --- |
| 核心大脑 | 负责对话、调用模型、调用工具 |
| 记忆服务 | 保存对话、重要事件、用户偏好，定时压缩 |
| 情绪服务 | 根据聊天内容产生情绪，情绪影响语气 |
| 联网服务 | 搜索互联网、读取网页内容 |
| 聊天服务 | 接入 Telegram，自动收发消息 |
| 内容服务 | 自动生成短视频选题、脚本、标题、话题 |
| 发布服务 | 抖音/TikTok 短视频发布（默认演示模式） |

## 二、运行环境要求

- Windows 电脑
- Python 3.11 或更高版本
- 不需要安装第三方 Python 包，项目只使用 Python 标准库

检查 Python 是否可用：

```powershell
python --version
```

如果显示类似 `Python 3.12.x`，说明可以直接运行。

## 三、最快体验（不用配置任何密钥）

### 方式一：双击启动脚本

双击项目根目录的：

```text
启动智能体.bat
```

### 方式二：命令行启动

在项目根目录打开 PowerShell，运行：

```powershell
python -m agent run
```

### 启动后你会看到

```text
你好，我是小忆。输入 /mood 看情绪，/memory 看记忆，/quit 退出。
你：
```

直接在 `你：` 后面输入文字聊天即可。

### 控制台命令

| 命令 | 作用 |
| --- | --- |
| `/mood` | 查看当前情绪 |
| `/memory` | 查看最近记忆 |
| `/quit` | 退出程序 |

## 四、配置真实 AI 对话

### 第 1 步：复制配置文件

在项目根目录找到 `.env.example`，复制一份并改名为 `.env`。

也可以直接在 PowerShell 里执行：

```powershell
Copy-Item .env.example .env
```

### 第 2 步：填写模型配置

用记事本打开 `.env`，找到下面几行并填写：

```text
AI_API_KEY=你的模型密钥
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini
```

### 常见模型服务商示例

OpenAI：

```text
AI_BASE_URL=https://api.openai.com/v1
AI_MODEL=gpt-4o-mini
```

DeepSeek：

```text
AI_BASE_URL=https://api.deepseek.com/v1
AI_MODEL=deepseek-chat
```

其他 OpenAI 兼容服务，把 `AI_BASE_URL` 和 `AI_MODEL` 改成服务商提供的即可。

### 第 3 步：重新启动

```powershell
python -m agent run
```

配置正确后，聊天会变成真实模型回复，不再显示“离线模式”。

## 五、接入 Telegram 聊天

### 第 1 步：创建 Telegram 机器人

1. 在 Telegram 里搜索 `@BotFather`。
2. 发送 `/newbot`。
3. 按提示设置机器人名字。
4. 设置机器人用户名，例如 `my_agent_bot`。
5. BotFather 会给你一串 `TOKEN`，形如：

```text
123456789:AAF...xxxx
```

### 第 2 步：写入配置

在 `.env` 里填写：

```text
TELEGRAM_BOT_TOKEN=123456789:AAF...xxxx
```

### 第 3 步：启动

```powershell
python -m agent run
```

启动日志会提示 Telegram 聊天服务已就绪。

### 第 4 步：测试

在 Telegram 里搜索你的机器人用户名，点“开始”，然后发一条消息。智能体会回复你。

## 六、开启真实联网搜索

默认是演示搜索，不会访问网络。需要真实搜索时，在 `.env` 填写：

```text
SEARCH_PROVIDER=tavily
SEARCH_API_KEY=你的搜索服务密钥
```

支持三种服务：

| 服务 | SEARCH_PROVIDER 值 | 申请地址 |
| --- | --- | --- |
| Tavily | `tavily` | tavily.com |
| Serper | `serper` | serper.dev |
| Brave | `brave` | brave.com/search/api/ |

申请后把 API Key 填进 `SEARCH_API_KEY`，重启即可。

## 七、短视频发布

### 默认安全模式

项目默认 `DRY_RUN=1`，即演示模式：

- 不会真的发视频
- 只会在本地记录“发布任务”
- 用于验证流程和测试

### 抖音

1. 到抖音开放平台申请开发者账号。
2. 创建应用，获得 `DOUYIN_CLIENT_KEY` 和 `DOUYIN_CLIENT_SECRET`。
3. 完成用户授权，拿到发布视频所需权限。
4. 在 `.env` 填写：

```text
DOUYIN_CLIENT_KEY=你的应用Key
DOUYIN_CLIENT_SECRET=你的应用Secret
DRY_RUN=0
```

### TikTok

1. 在 TikTok Developer Portal 创建应用。
2. 申请 Content Posting API 权限。
3. 在 `.env` 填写：

```text
TIKTOK_CLIENT_KEY=你的ClientKey
TIKTOK_CLIENT_SECRET=你的ClientSecret
DRY_RUN=0
```

### 重要提醒

- 不要使用个人账号自动化脚本，容易违反平台规则。
- 未完成授权前，请保持 `DRY_RUN=1`。
- 发布失败时，任务状态会记录在 `data/content.db` 里。

## 八、常用启动方式

### 全部模块并行运行

```powershell
python -m agent run
```

默认启动：控制台对话 + 记忆 + 情绪 + 联网 + 聊天 + 内容 + 发布。

### 只跑控制台对话

```powershell

```

### 只跑 Telegram

```powershell

```

### 指定配置文件

```powershell

```

### 后台常驻运行（关掉终端也能继续）

双击 `启动后台.bat`，程序会用无窗口模式在后台运行，不会占用终端。

想要开机自动启动，可以注册 Windows 计划任务：

```powershell
schtasks /create /tn "AI智能体后台" /tr "\"C:\Users\袁\Documents\ChatGPT\ai智能体\启动后台.bat\"" /sc onlogon /rl LIMITED /f
```

之后每次登录 Windows 都会自动启动，关掉终端也不影响。

## 八点五、监控与调试面板

后台默认启动 `monitor` 和 `debug` 两个模块，运行数据统一保存在 `data/monitor.db`。

### 打开网页版

```powershell
python -m scripts.serve_dashboard
```

浏览器访问：

```text
http://127.0.0.1:8765
```

### 打开悬浮窗

```powershell
python -m scripts.open_dashboard
```

### 面板包含

- 监控页：总 Token、今日对话、当前情绪、模块状态，Token/情绪/记忆趋势图，最近对话、模型调用和发布任务。
- 调试页：实时日志流（全部/INFO/WARNING/ERROR 过滤）、事件总线记录、模块运行状态、配置概览。
- 配置概览不会显示密钥原文，只显示“已配置”或“未配置”。
- 监控页每 1 秒刷新，调试页每 3 秒刷新；Tk 悬浮窗由 `DASHBOARD_REFRESH_SECONDS` 控制，默认 15 秒。

### 调试数据保留

日志、事件和模块状态默认保留 30 天，由 `MONITOR_CLEANUP_DAYS` 控制。日志与事件内容最多截断 2000 字。

## 九点五、如何让对话更有人情味

1. 修改 `.env` 里的 `AGENT_PERSONA`，改成你喜欢的性格描述。
2. 示例：

```text
AGENT_PERSONA=温柔、幽默、有点碎碎念，像认识很久的老朋友；会主动关心，也会偶尔开玩笑。
```

3. 智能体会自动结合情绪和记忆：
   - 你低落时先共情，再给建议。
   - 聊到你之前提过的事情时，会自然带出来。
   - 回答不会像客服，会适当追问，让对话继续。
4. 改完保存 `.env`，重新启动即可生效。

### 让它像真人一样“想一下再说”

默认已经开启：

- 每次回复前会犹豫 0.8~2.2 秒，模拟思考。
- 长回答会拆成 2~3 段，逐条发送，中间停 0.8 秒。

想关闭，就在 `.env` 里设置：

```text
AGENT_MULTI_REPLY=0
AGENT_THINKING_MIN=0
AGENT_THINKING_MAX=0
```

## 十二、常见问题

### 1. 提示找不到 `python`

安装 Python 3.11+，或者使用 Codex 自带运行环境。

### 2. 聊天回复“离线模式”

说明还没有配置 `AI_API_KEY`，或密钥填写有误。检查 `.env`。

### 3. Telegram 没回复

- 检查 `TELEGRAM_BOT_TOKEN` 是否正确。
- 确认电脑能访问 Telegram。
- 确认 `.env` 保存后重新启动了程序。

### 4. 搜索返回演示结果

说明 `SEARCH_PROVIDER` 还是 `dry_run`，或 `SEARCH_API_KEY` 为空。

### 5. 发视频提示演示模式

说明 `DRY_RUN` 还是 `1`，或平台凭证未配置。

### 6. 想清空记忆

关闭程序后删除：

```text
data/memory.db
```

下次启动会自动重新创建。
