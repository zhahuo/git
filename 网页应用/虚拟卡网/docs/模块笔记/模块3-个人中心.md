# 模块3 个人中心

## 实现内容

- 注册/登录：`src/app/auth/register/page.tsx`、`src/app/auth/login/page.tsx` 及表单组件，支持 `?next=` 回跳；登录使用 httpOnly 会话 Cookie。
- 个人中心概览：`src/app/account/page.tsx`，用户名/昵称、余额、订单统计与最近订单入口。
- 我的订单：`src/app/account/orders/page.tsx`，订单列表（状态徽章、金额、时间）；订单详情 `src/app/account/orders/[id]/page.tsx` 展示商品明细、支付信息与已发货卡密。
- 卡密查看与复制：`src/components/account/copy-button.tsx`、`cards-list.tsx`，`/account/cards` 汇总已购卡密，一键复制并反馈。
- 余额记录：`/account/balance`，当前余额、演示充值按钮（10/50/100 元）、`balance_logs` 流水表。
- 鉴权：`src/components/account/require-auth.tsx`，未登录跳 `/auth/login?next=原路径`。

## 验证

- `pnpm typecheck` 通过。
- 模块会话用 `NEXT_DIST_DIR=.next-m3` + 端口 3102 做了 API 链路与浏览器全流程验证：登录、下单、模拟支付后订单详情展示卡密、复制、充值流水；登录流程改为整页跳转避免 RSC 空响应问题。
- 验证完成后 dev 服务器已停止。

## 遗留问题

- 卡密复制依赖浏览器 clipboard 权限，HTTP 本地环境可用；生产环境建议启用 HTTPS。
