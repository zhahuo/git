## 8. 遗留问题

- 支付流程将 `pending` 直接推进 `delivered`，`paid` 为保留中间状态；管理端“发货”仅对 `paid` 订单可用，公共 API 无生成 `paid` 订单的路径，冒烟测试通过直接写库置为 `paid` 覆盖该分支。
- 购物车金额在商品刷新前使用本地快照，下单金额始终以服务端核算为准。
- 卡密复制依赖浏览器 Clipboard API，生产环境建议启用 HTTPS。
- 后台订单明细对单商品超过 200 张已售卡密时可能截断（当前真实订单量级不受影响，模块4 遗留）。
- Docker 镜像未在本机实际构建验证（本机无 Docker）；建议在目标服务器首次构建时核对 `pnpm --frozen-lockfile` 与卷权限。
