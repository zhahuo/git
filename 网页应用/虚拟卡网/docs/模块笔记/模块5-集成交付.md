### 2.2 后台概览用户数

- `src/app/api/admin/stats/route.ts` 新增 `totalUsers`（`SELECT COUNT(*) FROM users`）。
- `src/app/admin/page.tsx` 用户数指标由占位 `—` 改为 `stats.totalUsers`。
- `API.md` 同步补充 `totalUsers` 字段说明。

### 2.3 并发种子写入竞态

首次 `pnpm build` 在 Next 多 worker 并行收集页面数据时出现 `UNIQUE constraint failed: users.username`：多个进程同时发现空库并写入种子。修复 `src/lib/seed.ts`：

- `seedIfEmpty` 改为先执行 `BEGIN IMMEDIATE`，在事务内重新检查用户数；
- 已有数据则直接提交返回，否则串行写入种子；
- 修复后 build 稳定通过。

### 2.4 商品封面品牌字裁切

视觉复核发现 `public/covers/steam.svg` 右下角 “STEAM” 在详情页方形 `object-cover` 展示与购物车圆角缩略图中被裁切。将品牌字改为 `text-anchor="end"` 并收进安全区（右缘 x=660、基线 y=495），重截后经视觉模型确认无裁切。

### 2.5 截图重叠检测

`scripts/screenshots.mjs` 内置文本重叠检测：只统计可见文本叶子元素，排除 fixed/sticky 元素，并跳过父子包含关系，避免按钮图标+文字、行内 span 等嵌套元素产生误报。最终 26 张截图重叠告警为 0。

## 8. 遗留问题

- 支付流程将 `pending` 直接推进 `delivered`，`paid` 为保留中间状态；管理端“发货”仅对 `paid` 订单可用，公共 API 无生成 `paid` 订单的路径，冒烟测试通过直接写库置为 `paid` 覆盖该分支。
- 购物车金额在商品刷新前使用本地快照，下单金额始终以服务端核算为准。
- 卡密复制依赖浏览器 Clipboard API，生产环境建议启用 HTTPS。
- 后台订单明细对单商品超过 200 张已售卡密时可能截断（当前真实订单量级不受影响，模块4 遗留）。
- Docker 镜像未在本机实际构建验证（本机无 Docker）；建议在目标服务器首次构建时核对 `pnpm --frozen-lockfile` 与卷权限。
