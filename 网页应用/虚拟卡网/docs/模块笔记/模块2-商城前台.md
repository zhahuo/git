# 模块2 商城前台

## 实现内容

- 全局布局与样式：`src/app/layout.tsx`、`src/app/globals.css`，白底头部导航（品牌、购物车角标、登录/注册、个人中心、admin 入口）、页脚；移动端导航可折叠不重叠。
- 首页商城：`src/app/page.tsx` + `ProductExplorer`，商品网格、分类筛选、防抖搜索、排序（最新/销量/价格升降）、骨架屏、空态与加购提示。
- 商品详情：`src/app/products/[id]/page.tsx` + `ProductDetail`，封面、描述、价格、库存、数量步进器、加入购物车、立即购买。
- 购物车：`src/app/cart/page.tsx` + `CartView`，localStorage 持久化、数量增减、删除/清空、实时刷新价格与库存、未登录去结算跳转登录。
- 结算：`src/app/checkout/page.tsx` + `CheckoutView`，订单项确认、备注（200 字）、提交 `POST /api/orders` 后进入收银台。
- 收银台：`src/app/pay/[orderId]/page.tsx` + `PayView`，订单摘要、模拟支付/余额支付、支付成功展示卡密并复制、自动跳转订单详情。
- 商品封面：`public/covers/*.svg`，10 张本地矢量封面（steam、steam-100、bilibili、iqiyi、tencent、netease、qqmusic、jd、meituan、card），种子商品全部有对应资源。

## 验证

- `pnpm typecheck` 通过。
- 模块会话用 `NEXT_DIST_DIR=.next-m2` + 端口 3101 实测首页、详情、加购、购物车、结算、下单、支付成功跳转；集成阶段补完详情/收银台页面后再次通过 typecheck 与页面访问验证。
- 全局布局与购物车上下文被模块3/4 复用。
