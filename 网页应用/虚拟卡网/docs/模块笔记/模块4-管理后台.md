# 模块4 管理后台实现笔记

## 1. 职责范围

本模块只交付管理后台：`src/app/admin/**`（鉴权布局与 5 个页面）、`src/components/admin/**`（后台共享组件）、`docs/模块笔记/模块4-管理后台.md`。未修改 `src/lib/**`、`src/app/api/**`、前台/个人中心页面、`package.json`、`API.md`、`README.md`。

## 2. 交付内容

### 2.1 后台布局

- `src/app/admin/layout.tsx` 为服务端布局：读取会话，未登录或非 admin 跳转 `/auth/login?next=/admin`。
- `src/components/admin/nav.tsx` 提供桌面左侧导航与移动端顶部导航（概览、商品、分类、卡密、订单），并包含返回商城、退出登录入口；侧栏定位在全局 sticky 头部（h-16）下方，避免遮挡模块2 的全局头部。

### 2.2 页面

- `/admin` 概览：今日/累计销售额与订单数、用户数（接口未提供，显示 `—`）、在售商品数（由 `/api/admin/products?status=active` 计算）、低库存预警、最近订单、分类销售排行，数据主要来自 `GET /api/admin/stats`。
- `/admin/products` 商品管理：搜索/分类/状态筛选，封面、名称、分类、价格、库存、销量、状态表格；新增/编辑弹窗（名称、分类、价格、原价、描述、封面、预警阈值、上下架）；行内上架/下架与删除；后端 409 删除保护直接提示后端文案。
- `/admin/categories` 分类管理：列表、新增/编辑（名称、别名、排序）、删除确认；删除后商品自动变为未分类（后端处理）。
- `/admin/cards` 卡密管理：商品选择与可用/总数库存卡；批量导入 textarea（每行一条，展示 `导入 N 条，跳过 M 条`）；状态筛选与内容搜索、分页、单条删除；已售卡密显示锁定且不可删。
- `/admin/orders` 订单管理：状态筛选、订单号/用户名搜索、分页；行内展开商品明细；已发货订单展开时通过 `/api/admin/cards?status=sold&product_id=...` 拉取并匹配 `order_item_id` 展示已发卡密；待支付可取消、已支付可发货。

### 2.3 共享层

- `src/components/admin/api.ts`：JSON 请求封装与后端错误文案提取。
- `src/components/admin/ui.tsx`：按钮、图标按钮、弹窗、确认框、徽章、分页、表单控件、空态等。
- `src/components/admin/status.tsx` / `format.ts`：订单/卡密/商品状态徽章，金额与 Asia/Shanghai 时间格式化。

## 4. 遗留问题

- `GET /api/admin/stats` 未返回用户数字段，概览页「用户数」显示 `—`；若模块1 后续在 stats 中补充 `user_count`，可去掉占位逻辑。在售商品数目前由 `/api/admin/products?status=active` 计算。
- `/api/admin/orders` 列表不含已发卡密，订单展开页按商品逐个请求 `/api/admin/cards?status=sold` 并用 `order_item_id` 匹配；单商品超过 200 张卡密时该商品明细可能被截断（当前真实订单量级不受影响）。
- 当前支付流程把 `pending` 直接推到 `delivered`，管理端「发货」只对 `paid` 订单可用；若后续引入人工收款流程，可复用模块1 的 `deliverOrder`。
- dev 验证期间出现过一次 `/api/admin/cards` 的瞬时 500（Next 开发态 manifest 重编译竞态），随后重试返回 200，未再复现，不影响功能。
