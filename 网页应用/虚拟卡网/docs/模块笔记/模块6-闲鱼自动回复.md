# 模块6 闲鱼自动回复

## 1. 职责范围

模块6 负责闲鱼自动回复后端的部署副本与自动回复配置，并作为发卡桥接（模块7）的
消息发送回端。交付物位于 `integrations/xianyu/`。

> 说明：本笔记由模块5 集成会话在工作区既有交付物基础上补齐（原模块6 会话未产出
> 笔记），内容以 `integrations/xianyu/` 实际文件为准，未改动模块功能代码。

## 2. 交付内容

- 后端主体：`reply_server.py`（FastAPI + Uvicorn），提供管理界面、自动回复、
  订单/消息事件、发送消息等接口；`Start.py` 为本地启动入口（后台启动 FastAPI 与
  闲鱼会话任务）。
- 自动回复配置：`global_config.yml -> AUTO_REPLY`（`enabled: true`、默认回复文案、
  API 回复开关 `api.enabled: false`、服务端口 8090），关键词/默认回复/AI 回复配置
  入口见该文件与 `docs/configuration.md`。
- 发送消息接口：`POST /send-message`，请求体
  `{ api_key, cookie_id, chat_id, to_user_id, message }`，用于桥接把卡密消息发回
  闲鱼买家；支持测试秘钥 `zhinina_test_key` 直接返回成功。
- 部署文件：`docker-compose.yml`（端口 `9000:8090`、VNC/noVNC、持久化
  `data/logs/backups`、健康检查 `/health`）、`docker-compose-cn.yml`（端口
  `8000:8090`）、`Dockerfile`/`Dockerfile-cn`、`entrypoint.sh`、`start.sh`、
  `stop.sh`、Windows 启动/停止脚本。
- 依赖：`requirements.txt`（fastapi/uvicorn/pydantic/loguru/aiohttp/playwright 等），
  工作区自带 Python 3.12 venv（依赖已安装）。
- 文档与配置示例：`README.md`、`docs/{deployment,configuration,usage,faq,release}.md`、
  `.env.example`、`global_config.yml`。

## 3. 与卡网/桥接的集成点

- 闲鱼「消息、拍下、付款」事件由模块6 后端转发到桥接 `POST /trigger`
  （`integrations/xianyu/bridge/server.mjs`，默认 `127.0.0.1:8787`）。
- 桥接完成领卡后，把卡密消息 POST 到模块6 的发送消息接口；桥接侧
  `config/settings.json -> sender.http.url` 为可配置地址，生产环境应指向本后端
  `http://<host>:8090/send-message`（注意：`settings.example.json` 中的
  `/api/reply/send` 与实际路由不一致，需按实际路由 `/send-message` 配置）。
- 卡网侧：`INTEGRATION_API_TOKEN` 由卡网进程注入，桥接与卡网之间通过
  `Authorization: Bearer <token>` 鉴权；对账记录见卡网后台「发卡记录」。

## 4. 验证结果

- 结构完整性：`integrations/xianyu/` 含完整后端源码、配置、Docker/Compose 与
  Python 3.12 venv（`venv/Scripts/python.exe` 可运行，依赖已安装），
  `reply_server.py` 可被 uvicorn 加载的接口（`/send-message`、`/health`、
  `/api/orders`、`/api/chat/*` 等）均已确认存在。
- 配置核验：`AUTO_REPLY.enabled=true`，默认回复文案与端口配置正常；
  docker-compose 健康检查指向 `http://localhost:8090/health`。
- 联调链路：桥接 mock 24 项、桥接真实卡网接口 5 项均通过（模块7 笔记），
  覆盖事件触发、领卡、幂等、库存不足与发送回调；模块5 另做全链路验证。
- 未验证项：本机未登录真实闲鱼会话，平台侧「收到消息→回复→发货」的实收发
  需在生产环境使用真实 Cookie/账号验证；AI 回复与验证码等能力未做在线实测。

## 5. 遗留问题

- 发送消息接口契约需在桥接 `settings.json` 中配置为 `/send-message`，并准备
  `api_key`、`cookie_id`、`chat_id`、`to_user_id` 字段来源（当前桥接回调带
  `buyer_id`/`session_id`，需与模块6 侧字段映射确认）。
- 生产部署必须覆盖默认密码/密钥：`ADMIN_PASSWORD`、`JWT_SECRET_KEY`、
  `/send-message` 的 API 秘钥，避免使用默认值。
- 闲鱼平台风控与接口变化可能导致自动回复/自动发货中断，需按
  `docs/faq.md` 与上游仓库更新机制维护。
