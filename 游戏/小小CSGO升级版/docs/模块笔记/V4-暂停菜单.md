# V4-暂停菜单

## 状态

已完成独立模块，文件为 `src/pause.js`。模块只负责暂停层、输入和动作分发，不修改游戏主循环。

## 默认接入

在 `index.html` 中、游戏主脚本之后加载：

```html
<script src="src/pause.js"></script>
```

模块会自动查找全局 `G`、`restart()`、`requestLock()`，因此当前 V3 游戏无需额外适配即可支持：

- `Esc` 打开 / 关闭暂停菜单
- 继续游戏
- 设置（优先调用 `V4Settings.open()`，否则派发 `v4:open-settings` 事件）
- 重开本局
- 回主菜单

暂停时 `G.running` 被置为 `false`，主循环中的游戏更新和 `G.time` 倒计时均停止；继续时恢复 `G.running`。打开暂停会退出 Pointer Lock，继续游戏会重新请求 Pointer Lock。

## 可选接入接口

需要由集成模块自定义行为时，在初始化时传入回调：

```js
V4Pause.init({
  getState: () => G,
  canPause: () => G.started && !G.over,
  setRunning: running => {
    G.running = running;
    G.paused = !running;
  },
  continueGame: () => requestLock(),
  openSettings: () => V4Settings.open(),
  restart: () => restart(),
  mainMenu: () => showStartScreen()
});
```

公开方法：`V4Pause.open()`、`V4Pause.close()`、`V4Pause.toggle()`、`V4Pause.isOpen()`、`V4Pause.init(options)`。

## 归属边界

本模块只创建并维护 `#v4PauseMenu`、`#v4PauseStyles`，并复用已有 `#pause` 容器；不修改 `index.html`、`settings.js`、`quality.js` 或其他模块文件。
