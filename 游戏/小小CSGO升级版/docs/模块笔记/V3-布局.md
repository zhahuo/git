# V3-布局 模块笔记

## 一、模块范围

- 场景布局：掩体分布、高低差、区域划分与推荐路线。
- UI/HUD 布局：三栏网格化 HUD、安全区适配、小窗/窄窗/超宽屏适配、低配降级。
- 加载性能：加载进度反馈、空闲调度、低配设备自动精简。
- 本模块只新建 `src/layout.js`、`src/layout.css`、`docs/模块笔记/V3-布局.md`，未修改 `index.html`、`maps.js`、`i18n.js` 等其它模块文件。

## 二、交付文件

| 文件 | 职责 |
| --- | --- |
| `src/layout.js` | 布局运行时：场景补丁、UI/HUD 布局、加载性能与对外接口。 |
| `src/layout.css` | HUD/开始页/加载条样式，与 `layout.js` 的 `v3-layout-*` 类配合。 |
| `docs/模块笔记/V3-布局.md` | 本笔记：接口登记与接入方式。 |

## 三、场景布局说明

### 掩体分布

新增 7 处掩体，优先填补中路、西侧入口和东侧空地，避免堵死现有巷道：

| 位置 | 类型 | 坐标 | 作用 |
| --- | --- | --- | --- |
| 中路碉堡 A | 水泥墩 | `(-1.8, -11.8)` | 阻断出生点直看仓库的长线 |
| 中路碉堡 B | 水泥墩 | `(1.6, -12.0)` | 与 A 形成斜向夹角 |
| 中路碉堡 C | 水泥墩 | `(-0.6, -15.2)` | 中路前压的第三处掩体 |
| 西侧入口 | 货箱 | `(-20.5, -13.5)` | 靠近斜坡入口的交火位 |
| 西侧中场 | 货箱 | `(-13.5, -10.5)` | 填补西侧开阔地 |
| 东侧庭院 | 货箱 | `(8.5, 7.5)` | 中央以东的转点掩体 |
| 东北角落 | 货箱 | `(23.5, 12.0)` | 东北区攻防支撑点 |

### 高低差

新增 4 处高低差，保留原巷道通行能力：

| 位置 | 类型 | 坐标 | 高度 |
| --- | --- | --- | --- |
| 西侧叠箱高台 | 二层集装箱 | `(-11, -4)` | 顶面 `5.70m` |
| 南侧叠箱高台 | 二层集装箱 | `(-4.5, -21.5)` | 顶面 `5.70m` |
| 东侧低台 | 混凝土平台 | `(22.6, -6.8)` | `0.90m` |
| 中央低台 | 混凝土平台 | `(4.2, 11.2)` | `0.80m` |

布局数据同时登记了现有高度层级（地面 `0`、货箱顶 `1.25`、集装箱顶 `2.85`、仓库二层 `4.42`、叠箱顶 `5.70`、仓库屋顶 `7.82`）以及三条推荐路线（东侧走廊、仓库斜坡、中央横穿），供 `maps.js` 或 V3-集成读取。

> 本批补丁坐标针对 `sector7` 集装箱仓库原图设计；新图接入前需先复核掩体与出生点、路线是否冲突。

## 四、UI / HUD 布局说明

- HUD 改为三栏网格：左上战术地图、顶部中央计时、右上击杀播报，左下生命/护甲、右下弹药/武器槽。
- 四角统一按视口边距与 `env(safe-area-inset-*)` 排布，适配异形屏与全屏模式。
- 视口较小时自动进入 `v3-layout-compact` / `v3-layout-dense`，缩小地图、弹药数字与武器槽文字。
- 超宽屏自动进入 `v3-layout-ultrawide`，左右两侧拉开，通讯条加宽。
- 低配设备自动进入 `v3-layout-lowend`，关闭 `backdrop-filter` 等开销较高的效果。

## 五、加载性能说明

- `V3Layout.loading.init()` 会在 `#boot` 内创建进度条，进度写入 CSS 变量 `--v3-boot-progress`。
- 集成方可在主脚本各初始化阶段调用 `V3Layout.loading.phase('maps', 20)` 等反馈进度；`#boot` 被隐藏时自动完成。
- `applyUI()` 等非关键布局通过 `requestIdleCallback`（无则回退 `setTimeout`）延迟执行。
- 根据 `hardwareConcurrency` / `deviceMemory` / 移动端 UA 判定低配，`applyScene()` 默认只落核心掩体与高台，跳过装饰性货箱与低台。

## 六、对外接口（登记给 V3-集成）

运行时挂载到 `window.V3Layout`：

| 接口 | 说明 |
| --- | --- |
| `V3Layout.version` | 模块版本 `1.0.0`。 |
| `V3Layout.scenePlan` | 场景布局数据：区域、高度层级、路线、掩体/高低差补丁。 |
| `V3Layout.applyScene(api?, options?)` | 应用场景补丁；`api` 可选 `{ materials, box }`，缺省回退到 `index.html` 的全局 `MAT` / `box`。 |
| `V3Layout.patchMapData(map, options?)` | 返回含补丁的新地图对象（不改动 `CSMaps` 原数据）；默认只处理 `sector7`，可用 `{ allMaps: true }` 或 `{ targetId: '...' }` 扩展。 |
| `V3Layout.applyUI()` | 应用 HUD/UI 布局类与响应式处理。 |
| `V3Layout.applyHUD(state?)` | 手动刷新 HUD；传对象直接写 DOM，不传则调用现有 `updateVitalsUI` / `updateAmmoUI`。 |
| `V3Layout.install(options?)` | 一键接入：`scene`、`ui`、`loading`、`autoScene`、`sceneApi`、`density`。 |
| `V3Layout.loading` | 加载进度控制器：`init()`、`set(pct)`、`phase(name, pct)`、`done()`。 |
| `V3Layout.performance` | 低配检测与降级：`detect()`、`reduce()`、`restore()`。 |
| `V3Layout.getTier()` | 返回 `'low'` 或 `'high'`。 |
| `V3Layout.on(event, fn)` | 监听 `installed` / `uiApplied` / `sceneApplied`。 |

## 七、接入步骤（由 V3-集成执行）

### 1. 引入样式与脚本

在 `index.html` 的内联 `<style>` 之后加入：

```html
<link rel="stylesheet" href="src/layout.css">
```

在游戏主 `<script>` 之前加入（此时 `#boot` 已存在于 DOM，可显示加载进度）：

```html
<script src="src/layout.js"></script>
```

### 2. 场景接线（推荐）

方式 A：使用 `maps.js` 的地图数据时，在渲染前合并补丁：

```js
const map = V3Layout.patchMapData(CSMaps.get(CSMaps.defaultId()));
```

默认只对 `sector7` 合并；若确认新图布局兼容，可传 `{ allMaps: true }` 或指定 `{ targetId: 'neon-dock' }`。

方式 B：直接对已构建场景打补丁，在主脚本内地图构建完成后、`spawnEnemies()` 之前调用一次：

```js
if (window.V3Layout) V3Layout.applyScene();
```

若 `maps.js` 已提供布局专用 API，则传入：

```js
V3Layout.applyScene({ materials: MAT, box });
```

两种方式二选一，不要同时使用，避免重复添加掩体。推荐方式 A：补丁进入地图数据后，碰撞、巡逻网格与小地图自动一致；方式 B 的推荐时机同样能让新增碰撞体进入敌人出生路线计算，若只能放到 `spawnEnemies()` 之后，仍可生效，但敌人的巡逻网格不会包含新掩体，仅靠运行时避障。

### 3. UI/HUD 接线

主脚本末尾或 DOM 就绪后调用：

```js
V3Layout.applyUI();
```

也可以直接 `V3Layout.install({ scene: false, ui: true, loading: true })`。未手动接场景时，`install()` 的 `autoScene` 会在游戏全局就绪后自动补一次 `applyScene()`。

### 4. 加载进度接线（可选）

```js
V3Layout.loading.phase('maps', 25);
V3Layout.loading.phase('hud', 60);
V3Layout.loading.phase('weapons', 85);
// #boot 隐藏时自动 done()
```

## 八、自检建议

```js
V3Layout.version === '1.0.0';
['low', 'high'].includes(V3Layout.getTier());
V3Layout.scenePlan.patches.cover.length >= 7;
V3Layout.scenePlan.heightLevels.length === 6;
const map = V3Layout.patchMapData(CSMaps.get(CSMaps.defaultId()));
map.cover.length > 100;
V3Layout.patchMapData(map).cover.length === map.cover.length;
// applyUI() 后：
document.documentElement.classList.contains('v3-layout') === true;
```

场景补丁建议验证：出生点出发沿中路、东侧走廊、西侧斜坡各走一遍，确认新增掩体不会把通道压到无法通过；从新增叠箱高台能正常跳下或换路。

## 九、边界说明

- 本模块不修改任何其它模块文件，实际页面验证需由 V3-集成接线后执行。
- 文案仍由 V3-汉化负责；本模块仅注入 `#v3BootBar` 一个非文案 DOM 节点。
- 低配判定只影响本模块的布局补丁密度，不修改渲染器与动态分辨率逻辑。
