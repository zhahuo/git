# V3-地图 模块笔记

## 文件归属

- 新建：`src/maps.js`
- 新建：`docs/模块笔记/V3-地图.md`
- 不改动：`index.html`、`src/layout.js`、`src/layout.css`、`src/i18n.js`、`src/lang/zh.js` 等其他模块文件。

## 目标

把 `index.html` 中写死的地图布局抽成独立数据模块，提供：

- 原集装箱仓库图（SECTOR 7）的完整可玩结构；
- 两张新图：霓虹码头、雪地基地；
- 每张图包含：玩家出生点、掩体、高低差、敌人巡逻路线、敌人刷新点；
- 不依赖 three.js、不操作 DOM，浏览器和 Node 都能加载。

## 对外接口

模块挂载为全局 `window.CSMaps`（Node 环境同时支持 `module.exports`）。

| 接口 | 说明 |
| --- | --- |
| `CSMaps.version` | 模块版本 `1.0.0` |
| `CSMaps.schemaVersion` | 数据 schema 版本 `v1` |
| `CSMaps.list()` | 返回所有地图的 `{ id, name, codename, subtitle, half }` 摘要 |
| `CSMaps.get(id)` | 按 id 取地图对象，找不到返回 `null` |
| `CSMaps.defaultId()` / `CSMaps.getDefault()` | 默认地图（`sector7`） |
| `CSMaps.enemyNames(map)` | 敌人名字数组 |
| `CSMaps.enemySpawns(map)` | 按敌人索引返回刷新点数组 |
| `CSMaps.coverCollider(cover)` | 单个掩体条目展开为 AABB |
| `CSMaps.toColliders(map)` | 整张图的碰撞盒（含坡道标记） |
| `CSMaps.validate(map)` / `CSMaps.validateAll()` | 边界、出生点、路线、掩体一致性自检 |

地图 id：

- `sector7`：集装箱仓库（原图）
- `neon-dock`：霓虹码头（新图）
- `snow-base`：雪地基地（新图）

## 地图数据 schema

```js
{
  id: 'sector7',
  name: '集装箱仓库',
  codename: 'SECTOR 7',
  subtitle: 'WAREHOUSE DISTRICT',
  half: 30,                  // 半边长，地图为 60x60
  theme: {                   // 供集成方选天空/雾/光照/小地图配色
    sky: 'industrial-dusk',
    fogColor: '#5a6872',
    fogDensity: 0.014,
    sunColor: '#ffd9a0',
    sunDirection: [0.55, 0.72, 0.42],
    ambient: '#9aa8b2',
    minimapBg: 'rgba(8,12,16,.82)',
    gridColor: 'rgba(120,140,160,.10)'
  },
  perimeter: {                // 边界围栏/隐形墙
    wallHeight: 12,
    thickness: 1.2,
    fenceHeight: 3.3
  },
  playerSpawns: [             // 玩家出生点，支持多选
    { id: 'south-gate', label: '南门', x: 0, z: 24, yaw: 0, floorY: 0 }
  ],
  defaultSpawn: 0,            // 默认使用第几个出生点
  enemies: {
    count: 10,
    names: ['VIPER', 'GHOST', 'REAPER', 'HAVOC', 'STRIKER', 'COBRA', 'TALON', 'WOLF', 'DIESEL', 'SHADOW'],
    grace: 3.0,               // 开局敌人停火时间，与原 GRACE_TIME 一致
    spawns: [                 // 每名敌人一个刷新点
      { routeIndex: 0, x: 16, z: -24, floorY: 0, label: '北走廊入口' }
    ]
  },
  routes: [                   // 巡逻路线，可循环航点
    {
      id: 'corridor-ns',
      label: '北南集装箱走廊',
      floorY: 0,              // 路线所在平面高度；上层路线填 4.42 / 1.8 / 3.2 等
      enemyIndexes: [0],
      waypoints: [[16,-22],[16,-6],[16,8],[16,20],[16,4]]
    }
  ],
  cover: [                    // 掩体条目，见下方 cover 说明
    { shape: 'box', w: 0.6, h: 9.5, d: 20.6, x: -29, y: 0, z: -4, mat: 'wall', ... }
  ],
  ramps: [                    // 高低差坡道
    {
      id: 'warehouse-ramp',
      x: -21.2, z: 15.2,
      width: 4.2, length: 9.5,
      baseY: 0, topY: 4.42,
      direction: '-Z',        // 向 -Z 升高，坡顶在 z - length/2
      minimap: { w: 4.2, d: 9.5, color: '#5d666e' },
      sideWalls: [ /* box 条目，坡道两侧挡墙 */ ]
    }
  ]
}
```

### cover 条目

- `shape: 'box'`：完整自由尺寸。`w/h/d` 为尺寸，`x/y/z` 为底面中心（`y` 是底面高度，与 `index.html` 的 `box()` 一致），`mat` 为材质名，可选的 `uvScale / collide / ground / ceiling / solid / minimap` 与原 `box()` 参数一一对应。
- `shape: 'container' | 'crate' | 'barrel' | 'jersey'`：使用内置通用几何，只写 `x/y/z`、`rotY` 和可选 `color`；尺寸见 `PRIMITIVES`。
- `rotY` 支持 `0` 或 `Math.PI/2`，表示宽/长互换（与原图集装箱旋转逻辑一致）。
- 掩体的 minimap 色块：优先读条目里的 `minimap`，否则使用该形状默认色。`CSMaps.toColliders()` 会输出 `{ minX, minY, minZ, maxX, maxY, maxZ, collide, walkable, minimap }`，集成方可用它生成 `colliders`、`groundMesh` 和 `mapRects`。

## 三张地图设计

### 集装箱仓库 `sector7`

原图结构的数据化：60x60，西侧二层仓库 + 4.42m 狙击平台 + 坡道，中央烧毁平板车，东侧双排集装箱走廊，北侧岗亭、隔离墩、中部长隔墙，散落木箱与油桶。10 条路线与原 `ROUTES` 完全对应，其中第 1、6 条为二层路线。两处微调：散落集装箱从 `(26,6.5)` 内移 0.6m 到 `(25.4,6.5)`，使掩体完全落在游戏区内；敌人刷新点全部显式给出且避开掩体。

### 霓虹码头 `neon-dock`

夜间港区：西侧仓库 + 1.8m 装卸平台（两条上层巡逻线），中央双排集装箱走廊，东侧岸桥起重机与 3.0m 货棚屋顶，北岸栈道，南部入口隔离墩。夜色调主题：蓝青色雾、霓虹风格小地图底色。玩家默认出生在南岸 `(0,24)`，另有东侧入口备用出生点。

### 雪地基地 `snow-base`

极地前哨：中央地堡二层 3.2m（两条上层巡逻线），东北 1.8m 瞭望塔，雪地涂装集装箱双排区，冰面隔离墙，出生区两侧沙袋。白天雪原主题：冷白雾、暖日光。玩家默认出生在南侧 `(0,26)`，另有西侧入口备用出生点。

## 与原 index.html 的映射

| 原 index.html | maps.js |
| --- | --- |
| `const HALF = 30` | `map.half` |
| `const SPAWN = { x, z }` | `map.playerSpawns[map.defaultSpawn]` |
| `const ROUTES = [...]` | `map.routes[].waypoints` |
| `const UPPER_ROUTES = new Set(...)` | `map.routes[].floorY > 0` |
| `const ENEMY_NAMES = [...]` | `map.enemies.names` |
| `const GRACE_TIME = 3.0` | `map.enemies.grace` |
| `addCollider(...)` | `CSMaps.toColliders(map)`（`collide` 条目） |
| `groundMesh` / `ceilMesh` | 同一条目的 `walkable` / `ceiling` |
| `mapRects.push({x,z,w,d,c})` | 同一条目的 `minimap` |
| 仓库坡道几何 | `map.ramps`（含 `sideWalls`） |
| 边界隐形墙 + 铁丝网 | `map.perimeter` + `map.half` |

## 接入说明（给 V3-集成）

1. 在 `index.html` 的内联脚本之前引入：
   `<script src="src/maps.js"></script>`
2. 开局时用 `const MAP = CSMaps.get(selectedMapId)` 取图，把 `HALF`、`SPAWN`、`ROUTES`、`UPPER_ROUTES`、`ENEMY_NAMES`、`GRACE_TIME` 改为读取 `MAP`。
3. 用 `CSMaps.toColliders(MAP)` 生成碰撞盒：
   - `collide !== false` 的条目进 `colliders` 与 `worldSolid`；
   - `walkable` 进 `groundMesh`；
   - `ceiling` 进 `ceilMesh`；
   - `minimap` 进 `mapRects`（`w/d` 缺省用碰撞盒尺寸）。
4. `ramp` 条目按 `baseY/topY/direction` 建斜面几何，`sideWalls` 按普通 box 处理；上层路线刷新敌人时把 `floorY` 作为站立高度。
5. 玩家出生点：`MAP.playerSpawns[MAP.defaultSpawn]`；敌人刷新：`CSMaps.enemySpawns(MAP)`。
6. 菜单/计分板文案可直接用 `MAP.name` 和 `MAP.codename`（汉化文件仍归 V3-汉化模块，本模块不写 i18n）。
7. 开发期执行 `CSMaps.validateAll()`，三图均需返回 `ok: true`；测试脚本可直接 `require('src/maps.js')`。

## 校验

已用 Node 执行 `CSMaps.validateAll()`，三张图均为 `ok: true`，无 errors、无 warnings。校验覆盖：出生点/刷新点越界、出生点与掩体重叠、路线航点越界、掩体越界、路线与敌人数一致性。
