# V3-汉化 模块笔记

## 一、模块范围

- 提取主界面、HUD、武器、操作提示、击杀播报、敌台通讯、结算页、加载/报错等全部用户可见英文文案。
- 交付中文文案模块：`src/i18n.js`（国际化运行时）+ `src/lang/zh.js`（默认中文语言包）。
- 默认语言为中文，保留后续增加英语等多语言语言包的能力。
- 本模块只新建上述三个文件，未修改 `index.html`、`maps.js`、`layout.js` 等其它模块文件。

## 二、交付文件

| 文件 | 职责 |
| --- | --- |
| `src/i18n.js` | 国际化运行时：注册语言包、查询/插值文案、切换语言、DOM 静态文案应用。 |
| `src/lang/zh.js` | 中文语言包，随运行时自动注册为 `zh`，并作为默认与回退语言。 |
| `docs/模块笔记/V3-汉化.md` | 本笔记：接口登记与接入方式。 |

## 三、对外接口（登记给 V3-集成）

运行时挂载到 `window.I18N`：

| 接口 | 说明 |
| --- | --- |
| `I18N.register(lang, dict)` | 注册语言包；`lang` 为 `'zh'`、`'en'` 等代码。 |
| `I18N.setLocale(lang)` | 切换当前语言；语言包未注册时返回 `false`。 |
| `I18N.getLocale()` | 返回当前语言代码。 |
| `I18N.locales()` | 返回已注册语言代码列表。 |
| `I18N.get(key, locale?)` | 取原始值，数组/对象会原样返回；可指定语言。 |
| `I18N.t(key, params)` | 取文案并替换 `{name}` 占位符；缺失时回退中文，再缺失返回 key。 |
| `I18N.html(key, params)` | 同 `t`，用于包含 `<br>`、`<span>` 等 HTML 的文案。 |
| `I18N.has(key)` | 当前语言（含中文回退）是否存在该键。 |
| `I18N.onChange(fn)` | 语言切换后回调 `fn(lang)`，便于动态节点刷新。 |
| `I18N.localizeText(el, key, params)` | 设置元素的 `textContent`。 |
| `I18N.localizeHtml(el, key, params)` | 设置元素的 `innerHTML`。 |
| `I18N.applyStatic(root?)` | 扫描 `[data-i18n]` 元素并应用静态文案。 |

## 四、默认中文与多语言扩展

默认 `locale` 固定为 `zh`，不随浏览器语言自动切换；需要切换时显式调用 `I18N.setLocale()`。

新增语言只需仿照 `src/lang/zh.js` 新建语言包，例如 `src/lang/en.js`：

```js
(function (global) {
  'use strict';
  const en = { hud: { map: { tactical: 'Tactical' } } };
  if (global.I18N) global.I18N.register('en', en);
  else global.I18N_EN = en;
})(typeof window !== 'undefined' ? window : globalThis);
```

语言包可在运行时前后任意顺序加载。切换示例：

```js
I18N.register('en', en);
I18N.setLocale('en');   // 返回 false 表示语言包未注册
I18N.getLocale();       // 'en'
```

## 五、接入步骤（由 V3-集成执行）

### 1. 引入脚本

在 `index.html` 的游戏主 `<script>` 之前加入：

```html
<script src="src/i18n.js"></script>
<script src="src/lang/zh.js"></script>
```

推荐顺序为先运行时后语言包，反向也可兼容。

### 2. 静态文案

给元素加 `data-i18n="key"`，DOM 就绪后调用一次 `I18N.applyStatic()`。包含 HTML 的元素再加 `data-i18n-html` 属性。

静态元素映射：

| 元素 | 原英文 | key |
| --- | --- | --- |
| `#mapWrap .lbl span:first-child` | Tactical | `hud.map.tactical` |
| `#mapMode` | SECTOR 7 | `hud.map.sector` |
| `#breathTag` | HOLD BREATH | `hud.breath` |
| `#vitals .lbl`（第一处） | Vitals | `hud.vitals` |
| `#vitals .sub .lbl` | Armor | `hud.armor` |

### 3. 动态文案

游戏 JS 中的硬编码字符串按下表替换：

| 位置 | 原字符串 | 替换为 |
| --- | --- | --- |
| `updateAmmoUI` 的 `UI.wname` | `w.name` | `I18N.t('weapons.' + w.id + '.name')` |
| `updateAmmoUI` 的 `UI.wmode` | SEMI AUTO / FULL AUTO / PUMP ACTION / BOLT ACTION | `hud.mode.semiAuto` / `fullAuto` / `pump` / `bolt` |
| `updateAmmoUI` 的 `UI.resNum` | `/ 210` | `I18N.t('hud.ammoReserve', {count: w.res})` |
| `updateAmmoUI` 的换弹提示 | NO AMMO / PRESS R TO RELOAD | `hud.reload.noAmmo` / `hud.reload.pressR` |
| `killFeed` | YOU | `hud.feed.you` |
| `pushComms` 调用处 | COMMAND | `comms.command` |
| `bearingWord` | NORTH...NORTH-WEST 数组 | `I18N.get('comms.bearings')[i]` |
| 枪声警报三句 | SHOTS FIRED / CONTACT / GUNFIRE | `comms.gunfire.shots` / `contact` / `sweeping` |
| 击杀后小队反应 | IS DOWN / MAN DOWN / WE LOST | `comms.down` / `manDown` / `lost` |
| 交战呼叫 | CONTACT / TARGET SPOTTED / EYES ON / HOSTILE | `comms.contact` / `spotted` / `eyesOn` / `hostile` |
| 侧翼、推进、换弹、丢失目标等呼叫 | FLANKING.../PUSHING UP/RELOADING... | `comms.flankingLeft` 等全部对应键 |
| `ENEMY_NAMES` | VIPER...SHADOW | `I18N.get('enemies.names')` |
| `endGame` 标题 | SECTOR CLEARED / KILLED IN ACTION / TIME EXPIRED | `end.winTitle` / `deadTitle` / `timeTitle` |
| `endGame` 标签 | MISSION REPORT // SUCCESS / FAILURE | `end.winTag` / `loseTag` |
| 结算 `sKills` | `/10` | `end.stats.killsSuffix` |
| 结算 `sAcc` | `%` | `end.stats.accuracySuffix` |
| three.js 加载失败 | FAILED TO LOAD THREE.JS — CHECK CONNECTION | `boot.failed` |

占位符示例：`I18N.t('comms.down', {name: I18N.get('enemies.names')[i], bearing: I18N.t('comms.bearings')[idx]})`。

### 4. 语言切换后的刷新

切换语言后，静态元素重新调用 `I18N.applyStatic()`，动态节点按原更新路径重刷；若接入方注册了 `I18N.onChange()`，可在回调中统一刷新。

### 5. 可选：世界贴图文字

`zh.js` 同时收录了 `world.*` 键（地面标线、仓库墙面、集装箱喷码、易碎品标签等）。这些是运行时 Canvas 贴图，字体与排版由地图/布局模块决定，是否本地化由 V3-集成统一评估。

```js
I18N.getLocale() === 'zh';
I18N.t('menu.cta') === '点击开始';
I18N.t('hud.objective', {kills: 3}) === '已消灭 3 / 10';
I18N.t('comms.down', {name: '毒蛇', bearing: '北'}) === '毒蛇 已倒下 —— 北';
I18N.get('enemies.names').length === 10;
```
