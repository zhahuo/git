# 3D枪战游戏网页版 · 对话与开发记录

> 本文件是该项目与开发对话的整理摘要，随源码一起打包交付，方便接手者快速了解来龙去脉。

## 一、项目简介

项目代号 **STRIKE//ZONE**，是一款可直接在浏览器打开游玩的 3D 第一人称枪战游戏：点开网页、选择模式、进入对局即可开始，支持联机房间、多种玩法、机器人与完整对战流程。

项目完全程序化实现（零外部素材、零外部网络依赖），开源借鉴的部分（经典 arena-shooter 的占领点规则、夺旗规则、击杀奖励循环等）都按 GitHub 上同类开源项目的思路重写并验证。

## 二、对话与开发过程摘要

### 2.1 最初的诉求

- 构建一个 3D 枪战游戏项目；
- 可联机、多玩法、网页版，点开就能玩；
- 自己去 GitHub 搜索开源相关项目做比较、找灵感，能照搬的开源部分直接照搬；
- 先做框架，再逐步推进，每完成一步都要检查测试；
- 界面需要更新日志；
- 完成后端服务器部署；
- 每完成 12 个关联小步骤 = 1 个中步骤；5 个中步骤 = 1 个大步骤；
- 每步完成必须：类型检查 + 生产构建 + 全量 Playwright 回归 + 更新日志 + 清理缓存；
- 每个中步骤完成后更新一次日志，版本按 0.1、0.2、0.3 递增；大步骤完成后大版本升级为 1.0、2.0、3.0；
- 不读取、不输出个人隐私信息；不操作项目范围外的文件、账户、系统配置或网络数据；
- 用户无法响应期间需自主持续推进，遇到问题自己查资料解决，不得停止；
- 每完成 12 步清理一次不需要的文件与缓存，并保证电脑安全。

### 2.2 执行方式

- 每开始一个新的中步骤 / 大步骤，先检索 GitHub 或技术资料，再动手实现；
- 每个中步骤的 12 个小步骤围绕同一工程目标，存在明确依赖；
- 每个大步骤的 5 个中步骤围绕同一大工程目标；
- 每步完成都跑类型检查、生产构建与全量 Playwright 回归；
- 每完成一个中步骤写一次更新日志（0.1 → 0.2 → 0.3 …，大步骤完成后 1.0 → 2.0 → 3.0 …）；
- 更新日志后仅清理项目目录内已核验的可再生产物和临时缓存（dist、test-results、work/full-run.log 等）。

## 三、当前已实现功能

### 3.1 游戏核心

- 3D 第一人称视角：Three.js / React Three Fiber 渲染，鼠标锁定瞄准；
- WASD 移动、Shift 冲刺、射击、换弹、装备切换；
- 权威服务器：输入帧模拟、位置校验、服务端命中判定、伤害、淘汰、重生；
- 多玩家联机：WebSocket 房间、实时快照、预测与回滚校正、断线重连与事件日志回放；
- 机器人（Bot）：寻路、导航网格、目标选择与战斗 AI；
- 击杀连杀奖励、护甲、弹药、武器点、巨型医疗等拾取物体系。

### 3.2 玩法模式

- 自由混战（FFA）；
- 团队死斗（TDM）：CT/T 分队、禁止队友伤害、回合制与比分板；
- 生存模式（Survival）：波次推进；
- 军备竞赛（Gun Game）：击杀换枪；
- 夺旗战（CTF）：抢旗、回旗、掉落回归、事件流、团队语音快捷指令、匿名战绩榜；
- 占领模式（Domination，进行中）：三张地图三个控制点，占领持续得分，先到分数上限获胜。

### 3.3 系统与体验

- 三张地图：STRIKE、CROSSFIRE、RUSTYARD（含碰撞体、导航点、CTF 基地与控制点）；
- 排位匹配与匿名评分榜、观战系统（房间列表、跟随视角、容量限制）；
- 程序化空间音频：武器音效、脚步、命中、环境与 UI 音效，零音频文件；
- 雷达、HUD、计分板、聊天、触屏操作、设置面板（灵敏度、音频）；
- 服务器健康端点、公平性监控、滥用防护、部署配置（端口、固定地图、房间上限）。

## 五、本地运行

环境要求：Node.js 18+（建议 20+）、pnpm。

```powershell
pnpm install
pnpm dev            # 前端开发服务器，默认 http://localhost:5173
pnpm dev:server     # 权威游戏服务器，默认 127.0.0.1:2567
```

打开 http://localhost:5173 即可试玩；双开浏览器窗口可测试联机同房。

生产构建：

```powershell
pnpm build
```

## 六、自动化测试

```powershell
pnpm test:e2e
```

全量 Playwright 回归覆盖首屏、3D 画布、进入对局、操控与射击、双人同步、服务器伤害判定、防作弊、Bot、导航、地图、雷达、音频、CTF、排位、观战、部署健康与占领模式等（最近一次全量回归 294 项：290 通过 / 4 跳过 / 0 失败）。

## 七、技术栈与目录结构

- 前端：React 19、TypeScript、Vite、Three.js、React Three Fiber、React Three Rapier、Zustand、lucide-react；
- 服务端：Node.js 原生 WebSocket（无框架）；
- 测试：Playwright（浏览器 E2E + 单元测试）；
- 依赖许可：MIT / Apache-2.0，详见 `THIRD_PARTY_NOTICES.md` 与 `licenses/`。

```
new-chat/
├─ server/   # 权威服务器：房间、战斗、地图、CTF、占领、Bot、排位、音频事件等
├─ src/      # 前端：终端界面、HUD、3D 场景、网络客户端、状态管理、UI 组件
├─ tests/    # Playwright 全量回归（单元 + 浏览器 E2E）
├─ docs/     # 本说明文件
└─ 配置文件   # package.json、vite.config.ts、tsconfig、playwright.config.ts 等
```
